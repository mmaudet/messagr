# The independent counterparty, pinned.
#
# A floating `matrix-nio[e2e]` would make the interoperability proof depend on
# whatever PyPI resolved on the day, which is the opposite of what an
# acceptance criterion should rest on. Taken from the crypto library's own
# level 2 requirements, which pin the same closure for the same reason.
#
# WHAT THIS COUNTERPARTY'S INDEPENDENCE IS AND IS NOT: nio 0.26 moved its
# ratchet to `vodozemac`, the same crate `matrix-sdk-crypto` uses, so a defect
# inside vodozemac passes both sides of this proof. Everything above it -- the
# /keys/* payloads, to-device routing, the megolm event body, session
# lifecycle -- is two independent implementations agreeing or not, and that is
# the layer this application's own code lives in.
matrix-nio[e2e]==0.26.0
